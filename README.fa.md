# magical_org – Telegram Signal Poster

🌐 [English](README.md) · **فارسی**

بات تلگرام با پنل ادمین شیشه‌ای (Inline) برای انتشار سیگنال معاملاتی. سیگنال را به بات می‌فرستی، خود بات در کانال پست می‌گذارد، قیمت زنده را دنبال می‌کند و مراحل معامله را در کانال ریپلای می‌کند. نیازی به اکانت کاربری یا سشن نیست؛ فقط بات را ادمین کانال کن.

## نصب سریع

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Mahersaber2024/magical_org/main/magical_org.sh)
```

نصب‌کننده، بات را در مسیر `/opt/magical_org` نصب می‌کند و یک منو باز می‌شود. گزینه‌ی `1) Install` را بزن. نصب‌کننده این کارها را انجام می‌دهد:

1. نصب پیش‌نیازهای سیستمی مثل Python 3.10+ و `python3-venv`.
2. دانلود ریپو در `/opt/magical_org`.
3. ساخت محیط مجازی پایتون و نصب پکیج‌های `requirements.txt`.
4. پرسیدن توکن بات، آیدی ادمین‌ها و تایم‌زون و ذخیره‌ی آن‌ها در `.env`.
5. ساخت و اجرای سرویس systemd با نام `magical_org`.

سرویس systemd بات را از `/opt/magical_org` اجرا می‌کند.

بعد از نصب، وضعیت سرویس را چک کن:

```bash
systemctl status magical_org
```

> نصب‌کننده باید با کاربر `root` روی لینوکس دارای `systemd` اجرا شود. ریپو باید public باشد و فایل `magical_org.sh` در ریشه‌ی شاخه‌ی `main` قرار بگیرد.

## مسیر نصب

مسیر پیش‌فرض نصب:

```text
/opt/magical_org
```

فایل‌های پروژه، محیط مجازی پایتون، `.env` و `data.json` در این پوشه ذخیره می‌شوند.

## نصب دستی

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-venv python3-pip

git clone https://github.com/Mahersaber2024/magical_org.git
cd magical_org

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cat > .env <<'ENV'
BOT_TOKEN=123456:ABC-your-bot-token
ADMIN_IDS=12345,67890
TIMEZONE=Asia/Tehran
DATA_FILE=data.json
ENV

python3 magical_org.py
```

## تنظیمات

فایل `.env` توسط نصب‌کننده ساخته می‌شود. برای تغییر توکن یا ادمین‌ها از گزینه‌ی `6) Change token / admins` در منوی نصب‌کننده استفاده کن، یا فایل را ویرایش و سرویس را ریستارت کن.

| کلید | توضیح | پیش‌فرض |
| --- | --- | --- |
| `BOT_TOKEN` | توکن بات از [@BotFather](https://t.me/BotFather) | – |
| `ADMIN_IDS` | آیدی عددی مالکان، جدا شده با کاما | – |
| `TIMEZONE` | تایم‌زون برای تاریخ شمسی داخل پست‌ها | `Asia/Tehran` |
| `DATA_FILE` | مسیر فایل داده‌ی JSON | `data.json` |

## مدیریت سرویس

```bash
systemctl start magical_org
systemctl stop magical_org
systemctl restart magical_org
systemctl status magical_org
```

مشاهده‌ی لاگ‌ها:

```bash
journalctl -u magical_org -f
```

خود اسکریپت نصب‌کننده هم همین کارها را انجام می‌دهد:

```bash
bash /opt/magical_org/magical_org.sh restart
bash /opt/magical_org/magical_org.sh status
bash /opt/magical_org/magical_org.sh logs
```

## آپدیت

نصب‌کننده را دوباره اجرا کن و `2) Update` را بزن، یا:

```bash
bash /opt/magical_org/magical_org.sh update
```

آپدیت، فایل‌های `.env` و `data.json` را نگه می‌دارد.

## حذف (Uninstall)

نصب‌کننده را اجرا کن و `7) Uninstall` را بزن، یا:

```bash
bash /opt/magical_org/magical_org.sh uninstall
```

می‌توانی انتخاب کنی فقط سرویس حذف شود یا همه‌ی محتوای `/opt/magical_org` (شامل `.env` و `data.json`).

## دستورات بات

- `/start` – باز کردن پنل ادمین.
- `/help` – نمایش راهنما.

بقیه‌ی امکانات فقط از طریق دکمه‌های شیشه‌ای منو در دسترس‌اند.

## پنل ادمین

دکمه‌های منوی اصلی:

| دکمه | کاربرد |
| --- | --- |
| 📋 معاملات فعال | لیست زنده با قیمت و R فعلی، کنسل Pending و بستن دستی معامله‌ی باز |
| 📈 آمار | مجموع R، وین‌ریت، بهترین/بدترین معامله و نتیجه‌ی هر کانال |
| 📊 پست گزارش | ارسال خلاصه‌ی عملکرد معاملات بسته‌شده به کانال |
| 📺 کانال‌ها | افزودن، تست (ادمین بودن/دسترسی پست بات) و حذف کانال |
| ⚙️ تنظیمات | پله‌های ریوارد، قانون Break-even، فاصله‌ی چک قیمت |
| 🛡 پنل ادمین | مدیریت ادمین‌ها، وضعیت سیستم، بکاپ، پاکسازی تاریخچه، ریستارت |
| ❓ راهنما | راهنمای استفاده |

برای عملیات حساس (حذف، کنسل، بستن، ریستارت) تأیید گرفته می‌شود.

### نقش‌ها

- **مالک**: آیدی‌های `ADMIN_IDS` در `.env`. می‌تواند ادمین اضافه/حذف کند، بکاپ بگیرد، تاریخچه را پاک کند و بات را ریستارت کند.
- **ادمین**: از داخل بات اضافه می‌شود (🛡 پنل ادمین ← 👥 ادمین‌ها ← ➕). از بات استفاده می‌کند ولی ادمین‌ها را مدیریت نمی‌کند.
- هر کس دیگری که `/start` بزند آیدی خودش را می‌بیند تا به مالک بدهد.

## استفاده

1. `/start` را بزن.
2. بات را به کانالت اضافه کن و **ادمین** کن (با دسترسی «ارسال پست»).
3. **کانال‌ها ← افزودن کانال**: `@username`، آیدی `-100…` یا لینک `t.me` کانال را بفرست. بات چک می‌کند که می‌تواند آنجا پست بگذارد.
4. سیگنال را بفرست:

```text
btc
Int81000
Tp87000
Sl80000
```

5. پیش‌نمایش می‌آید (Risk/Reward خودکار محاسبه شده)، کانال را انتخاب کن و پست می‌شود.

## چرخه‌ی معامله

- 🟡 Pending پست می‌شود.
- قیمت به Entry رسید ← «Position Opened» (ریپلای روی Pending).
- کنسل از «معاملات فعال» ← «Pending Order Cancelled» روی همان پست.
- رسیدن به هر پله‌ی ریوارد (تنظیم‌پذیر) ← «Reward 1R reached — In Profit».
- رسیدن به TP یا SL ← پست نتیجه با R نهایی.
- «پست گزارش» ← خلاصه با نتیجه‌ی هر معامله، مجموع R، وین‌ریت و ریوارددهای جمع‌شده.

## قیمت زنده

از API عمومی Binance (با fallback به Bybit) و بدون هیچ کلید شخصی. دقت تشخیص برخورد برابر فاصله‌ی چک است (پیش‌فرض ۵ ثانیه)؛ شدو/ویکِ خیلی کوتاه بین دو چک ممکن است دیده نشود.

## ساختار پروژه

```text
magical_org.py    تنظیمات (.env) + ذخیره‌سازی (data.json) + منوها/هندلرها + مانیتور قیمت
trading.py        پارس سیگنال · قیمت زنده · تاریخ شمسی/فرمت اعداد · قالب پست‌های کانال
magical_org.sh    منوی نصب / آپدیت / حذف
```

## نکته‌ی امنیتی

فایل `.env` (شامل توکن بات) و `data.json` هرگز نباید روی گیت‌هاب بروند. دکمه‌ی بکاپ فقط `data.json` را می‌فرستد.
