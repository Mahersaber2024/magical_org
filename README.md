# magical_org — Telegram Signal Poster

بات تلگرام با پنل ادمین. سیگنال را به بات می‌فرستی، بات از طریق سشن (اکانت کاربری) در کانال پست می‌گذارد، قیمت زنده را دنبال می‌کند و مراحل معامله را در کانال ریپلای می‌کند.

## نصب (Linux)
```bash
git clone https://github.com/Mahersaber2024/magical_org.git
cd magical_org
bash install.sh
```
اسکریپت پایتون ۳.۱۰+ را چک می‌کند، venv می‌سازد، پکیج‌ها را نصب می‌کند، توکن و آیدی ادمین را می‌پرسد و اختیاری سرویس systemd می‌سازد.

اجرای دستی:
```bash
source venv/bin/activate && python magical_org.py
```

## ساختار پروژه
```
magical_org.py       تنظیمات (.env) + ذخیره‌سازی (data.json) + منوها/هندلرها + مانیتور قیمت
trading.py     پارس سیگنال · قیمت زنده · تاریخ شمسی/فرمت اعداد · قالب پست‌های کانال
poster.py      لاگین سشن و پست با Telethon
install.sh     نصب خودکار
session/       مدیریت سشن‌ها و پراکسی (رمزنگاری‌شده)
```

## استفاده
1. `/start` را بزن.
2. **سشن‌ها → افزودن سشن**: نام، api_id، api_hash، شماره، (پراکسی اختیاری)، کد، (رمز دو مرحله‌ای).
   کد را با فاصله بفرست (`1 2 3 4 5`) تا تلگرام باطلش نکند.
3. **کانال‌ها → افزودن کانال**: آیدی کانال را بده و سشنی را انتخاب کن که در آن کانال ادمین با دسترسی پست است.
4. سیگنال را بفرست:
```
btc
Int81000
Tp87000
Sl80000
```
5. پیش‌نمایش می‌آید (Risk/Reward خودکار محاسبه شده)، کانال را انتخاب کن و پست می‌شود.

## چرخه‌ی معامله
- 🟡 Pending پست می‌شود.
- قیمت به Entry رسید ← پست «Position Opened» (ریپلای روی Pending).
- کنسل از «معاملات فعال» ← ریپلای «Pending Order Cancelled» روی همان پست.
- رسیدن به هر پله‌ی ریوارد (تنظیم‌پذیر) ← پست «Reward 1R reached — In Profit».
- رسیدن به TP یا SL ← پست نتیجه با R نهایی.
- «پست گزارش» ← پست خلاصه با نتیجه‌ی هر معامله، مجموع R، وین‌ریت و ریوارددهای جمع‌شده.

## تنظیمات ادمین
پله‌های ریوارد (مثلاً `1,2,3`)، انتقال SL به Entry بعد از ریوارد دلخواه، و فاصله‌ی چک قیمت.

## قیمت زنده
از API عمومی Binance (و fallback به Bybit) بدون هیچ کلید شخصی.
دقت تشخیص برخورد قیمت برابر فاصله‌ی چک است (پیش‌فرض ۵ ثانیه)؛ شدو/ویکِ خیلی کوتاه‌تر ممکن است دیده نشود.

## نکته‌ی امنیتی
پوشه‌ی `session/` (فایل‌های `.session` و کلیدها) و `.env` هرگز نباید روی گیت‌هاب بروند. `.gitignore` این‌ها را نادیده می‌گیرد.
